# PU Transit

University bus tracking for students, drivers and transport administrators.

## Current owner amendment (13 Sep 2026)

- The product continues as the web app **PU Transit**. Native driver tracking is later work. The owner reports that the official Play app is being discontinued; this is owner-reported, not independently verified here.
- Sign-up has a student/staff/driver/admin role picker. PU student/staff access is approved immediately; driver/admin requests are approved as student plus `requestedRole` until the office confirms the role in **Admin → Users**. A requested role is never authority by itself.
- A new student using a personal email has a 30-day grace period from membership `createdAt`, enforced by Rules and the API. The student must switch to a verified university email from Account. Existing memberships are never wiped or recreated, and there are no automatic suspensions.
- The established root account remains protected. Do not add Firebase Console role-promotion instructions; future driver/admin confirmation is handled in Users.
- Current add-ons are `toCampus` / `fromCampus` plus a `full` flag; route kind includes `shuttle`; admin notices are created/deleted by admins, limited to 280 characters and 30 days; About/Help is included. Driver UI Hindi/Gujarati support awaits native-speaker review. Payments and passes are excluded.
- PU blue remains pinned to `#0A76D6`, not indigo. See `docs/evidence/2026-09-13-access-model.md` for the authoritative record and publication status.

## Run & Operate

- `pnpm --filter @workspace/api-server run dev` — run the API server (port 5000)
- `pnpm run typecheck` — full typecheck across all packages
- `pnpm run build` — typecheck + build all packages
- `pnpm --filter @workspace/api-spec run codegen` — regenerate API hooks and Zod schemas from the OpenAPI spec
- `pnpm --filter @workspace/db run push` — push DB schema changes (dev only)
- Required managed env: `FIREBASE_PROJECT_ID`, `FIREBASE_DATABASE_URL`, `UNIVERSITY_EMAIL_DOMAINS`. `DATABASE_URL` is needed only when legacy routes preview/import is explicitly invoked, not at startup. `ORS_API_KEY` is a server-only optional secret for the geo proxy (missing secret returns 503).
- `pnpm --filter @workspace/pu-transit run dev` — run the web app (reads `PORT`)

## Gotchas (maps)

- MapLibre 6 resolves its web worker from `import.meta.url`, which 404s under Vite; `vector-basemap.tsx` imports the worker with `?worker&url` and calls `setWorkerUrl()`. Any new MapLibre entry point needs the same. Verify the vector map with a WebGL-capable browser; headless screenshots without WebGL only show the raster fallback.
- ORS geocoding and directions are called only by the server-side admin-gated geo proxy; no browser ORS key or provider call is intended. Manual map-click routes remain allowed existing behavior, and provider failure never becomes synthesized road geometry. Local automated/build verification passed ([evidence](docs/evidence/2026-09-13-w0-04-ors-proxy.md)); server-secret/new-key comparison and live-provider check passed 13 Sep; old-key revocation at ORS is still pending (the old key was still accepted at the last check), so W0-04 is not complete.
